## ✨ Features
- 🚀 **Fast & Lightweight**: Built for speed directly in your CLI workflow.
- 🎨 **Smart Sync**: Keep your design tokens or style configs consistent across workspace files.
- ⚙️ **Configurable**: Easily tweak settings via `stylesync.config.json`.
- 🛡️ **Zero-leak**: Built-in environment variable protection.

## 📦 Installation

Make sure you have **Node.js (>=18)** installed on your machine.

Clone the repository and install dependencies:
```bash
git clone [https://github.com/kolweoe/stylesync-cli.git](https://github.com/kolweoe/stylesync-cli.git)
cd stylesync-cli
npm install
